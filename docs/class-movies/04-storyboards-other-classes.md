# Storyboards: the other twelve classes

Written so production can begin as soon as the first movie passes your review. Each is built on the same five acts as the Reaper's, but with its own world, camera language, effect and music.

Abbreviations: `LS` wide, `MS` medium, `CU` close-up, `ECU` extreme close-up, `OTS` over the shoulder. Music: `Op` atmosphere, `Th` emotional theme, `Te` tension, `Ac` action, `Cl` evolution climax, `En` ending.
