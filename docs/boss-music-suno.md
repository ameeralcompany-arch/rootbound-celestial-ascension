# Boss soundtrack: Suno prompts

This session has no Suno connection, so these are the prompts to paste into Suno yourself. Each boss gets four pieces: three phases that share one key and tempo so they can crossfade on any beat, and a short victory piece. Make every piece **instrumental** (Suno's Instrumental switch on). Keep each phase at least 2 minutes long so it can loop without the repeat being obvious.

When you have a file, save it as `audio/music/<boss id>_<piece>.mp3`, for example `audio/music/varkhazan_p2.mp3`. The pieces are `p1`, `p2`, `p3` and `win`. Any boss with no files keeps its built-in music.

| Boss in the game | Musical identity | Boss id | Key, tempo |
|---|---|---|---|
| The Ancient Sentinel | The Ancient Guardian | `sentinel` | D minor, 92 BPM |
| The Infernal Sovereign | The Executioner | `sovereign2` | C minor, 150 BPM |
| The Fallen Star | The Celestial Devourer | `fallenstar` | F# minor, 110 BPM |
| The World Eater's shadow (Eternal Abyss) | The Berserker | `worldeater0` | E minor, 172 BPM |
| The Nameless One (Hollow Sanctuary's boss) | The Phantom | `saint` | B minor, 78 BPM |
| The Hollow King | The Last King | `hollowking` | G minor, 96 BPM |
| Varkhazan | The Storm Colossus | `varkhazan` | D minor, 128 BPM |

Every prompt below asks for no vocals except wordless choir pads, and no religious words or imagery.
