# Where every cosmetic comes from

Written by `tools/looks-catalog.js` from `server/catalog.json`. Since master update 2, no cosmetic is sold in the store: each one is **exclusive**, earned by playing (or, for the rare finds, found by breaking natural blocks). Everything a player already owned stays owned.

The game checks your progress every few seconds and grants an item the moment its goal is met; online, the server records it on your account. Goals rise with rarity.
