Rootbound desktop wrapper (Electron). NOT BUILT/VERIFIED in the authoring sandbox (no access to the npm/GitHub binary hosts there).
On Windows with Node.js 18+: double-click build-windows.bat -> dist\Rootbound-win32-x64\Rootbound.exe
Or run "npm install && npm start" to test it in a window first. index.html is the same standalone game build.
Note: PeerJS multiplayer loads from a CDN, so rooms need internet access.
