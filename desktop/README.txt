Rootbound desktop app (Electron). Single-player: it never goes online, and your save lives on this PC.
On Windows with Node.js 18+: copy ..\index.html here, then double-click build-windows.bat -> dist\Rootbound-win32-x64\Rootbound.exe
Or run "npm install && npm start" to test it in a window first. index.html is the same standalone game build.
F11 toggles fullscreen. If the window stays black, start Rootbound-Safe-Mode.bat instead (turns hardware acceleration off).
