Rootbound for Windows (Electron). This is the only way to play: the game does not run in a browser.
It connects to the online server for accounts and shared worlds, and can be played without it. Offline saves live on this PC.
On Windows with Node.js 18+: copy ..\index.html and the ..\audio and ..\assets folders here, then double-click build-windows.bat -> dist\Rootbound-win32-x64\Rootbound.exe
Or run "npm install && npm start" to test it in a window first.
F11 toggles fullscreen. If the window stays black, start Rootbound-Safe-Mode.bat instead (turns hardware acceleration off).
