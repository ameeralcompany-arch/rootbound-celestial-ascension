Rootbound

A 2D anime block sandbox. It is a Windows game now, and it no longer runs in a browser.

Download for Windows

Windows 10 or newer, about 180 MB

How to start

  1. Right-click Rootbound-Windows.zip and choose Extract All.
  2. Open the extracted folder and run Rootbound.exe.
  3. If Windows says it protected your PC, click More info, then Run anyway. The app isn't code-signed yet.

Played here before?

If you have an account, sign in with the same name in the app. Your progress comes with you.

You also have progress saved in this browser. Save it to a file, then in the app open Settings > General > Backup & restore and choose Import save file.
